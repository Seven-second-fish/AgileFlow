# 缺陷追踪模板

> 按需创建到 `atlas/bugs/`。批量、跨层、阻塞、重开或高风险缺陷须落盘；
> 单个且当场闭环的轻微 `/af-fix` 只留命令与测试证据。
> 状态只在 `atlas/bugs/README.md` 维护；详情文件不重复状态。

### 固定值

- **REQ 判定**：`已覆盖`、`需求漏记`、`需求含糊`、`新需求`
- **归因**：`实现遗漏`、`实现错误`、`solution/model 问题`、`需求缺陷`、`测试缺陷`、`新需求`
- **状态主链**：`待核对需求` → `待补需求` / `待修实现` / `待修测试` → `待回归` → `已关闭`
- **辅助状态**：`阻塞`、`已转需求`、`重复`

`BUG-xxx` 项目内递增且永不复用。进入 `待修实现`、`待修测试`、`待回归`
或 `已关闭` 前，必须已有 REQ + AC；`已转需求` 必须链接新 REQ。

## 关闭条件

同时满足才可在总表标记 `已关闭`：

1. REQ/AC 已存在且语义明确。
2. 原复现步骤不再失败。
3. 回归测试已补并通过；不能自动化时写人工证据与原因。
4. 受影响文档已同步。
5. `回归测试` 单元格已填写可复核证据。
